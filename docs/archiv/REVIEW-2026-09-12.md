## TL;DR

1. **One production-breaking bug**: the `training_data` table exists in no Alembic migration (B-39). Every
   prod deploy with `ENVIRONMENT=production` (which forbids `create_all`) breaks Banana import and every training job.
2. **The role ladder is not wired**: `require_editor` / `require_admin` exist (`core/deps.py:55-75`) but no router
   uses them — an SSO `viewer` can wipe the Kontenplan, delete the model, import with `replace=true` (B-40).
3. **`docker compose up` is a dev stack**: no `ENVIRONMENT=production`, `--reload`, `SECRET_KEY=""` tolerated,
   DB/Redis/Ollama published on 0.0.0.0, worker also runs `alembic upgrade` (B-41).
4. Two authenticated abuse paths: SSRF through tenant-editable `ollama_base_url` (B-42) and an open mail relay with
   unescaped HTML via `/api/export/email/rows` (B-43).
5. The **self-learning loop is dead on the Kontoauszug path** — the frontend posts the *edited* account as
   `original_soll`, so no `Correction` is ever logged (B-45). The 4 settings tabs "save" with a 600 ms sleep (B-46).

Verdict: **Request changes before any production deploy.** The tenant filtering, JWT/SSO/HMAC, money rounding,
pickle signing and the error envelope are done right — do not touch those (see "What is solid").

## 3. What is solid — do not touch

- **Tenant scoping is uniform.** Every tenant-table query filters on `tenant_id` from `get_current_user` (`core/deps.py:14-44`); no route takes a tenant id from body/query; `{id}` routes combine id + tenant and 404 (`bookings.py:134`, `review_queue.py:70-77`, `classify.py:129-153`); 30+ routes in `test_tenant_isolation.py`.
- **Storage keys are tenant-bound and path-safe** (`services/receipts.py:48-67`, `storage.py:47-71`, tests).
- **JWT / SSO / HMAC.** Fixed alg list, `exp`, `type=access`, `tid` cross-checked against DB, `is_active` gate (`security.py:35-39`, `deps.py:27-42`). SSO: HS256 pinned, `iss/type`, `exp-iat ≤ 120 s`, DB-backed `jti` nonce in a savepoint → replay-safe across workers (`sso.py:86-144`); email-takeover guard (`:219-228`); shadow users refused at `/login` before bcrypt. Events: HMAC over `ts.body`, `compare_digest`, ±5 min, verified before JSON parse, `Decimal` amounts (`platform_events.py:51-69,139-146`).
- **Pickle is verified before unpickling on both paths** (`classify.py:283-300,336`, `model_blob.py:51-58`, `classifier.py:221-225`); `defusedxml` for Banana XML.
- **Money rounding** `round_chf`/`fmt_swiss` are correct half-up via `Decimal(repr(float))` with the float-trap cases pinned (`export.py:16-42`, `test_export.py:87-123`).
- **Error envelope + prod hardening**: no stack traces on 500, Sentry `send_default_pii=False`, docs off in prod, prod refuses default secret / wildcard CORS / `create_all` (`config.py:138-151`).
- **Job claim** is a conditional `UPDATE … WHERE status='pending'` (`training_worker.py:75-81`); `ScannerConfigService.get_or_create` savepoint race fix with a concurrency test; B-04 data migration freezes both preprocess versions and has a PG round-trip test.
- **Frontend**: `lib/errors.ts` + `ErrorState` (tested), `useFocusTrap` (Tab cycling, Esc, restore), `/sso` page (fragment token read once, StrictMode-safe, `replaceState`), theme tokens mapped from platform `--cd-*` with `@custom-variant dark` and reduced-motion, `lib/navigation.ts` as the single nav source, `Button loading` on most mutations.
